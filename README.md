# Korboly — site

Página única (HTML/CSS/JS, sem build). Os botões levam à loja em korboly.com.

## Publicar no GitHub Pages
1. Suba estes arquivos na raiz do repositório (branch `main`).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / root.
3. (Opcional) domínio próprio: crie um arquivo `CNAME` com o domínio e aponte o DNS.
